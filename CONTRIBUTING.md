# Contributing to ChatSpy

For minor fixes, open a PR directly. For anything larger, open an issue first
so the maintainers can agree on the approach before you start work.

Setup, commands, architecture, and the contribution workflow live in the
[Developer Guide](packages/docs/content/docs/developer-guide/).

## License

ChatSpy is licensed under the [MIT License](LICENSE.md). By contributing, you

## Code of Conduct

By participating in this project you agree to abide by our
[Code of Conduct](CODE_OF_CONDUCT.md). Report violations to the maintainers.

## Reporting Security Issues

Please do not open a public issue for security vulnerabilities. See
[`SECURITY.md`](SECURITY.md).
